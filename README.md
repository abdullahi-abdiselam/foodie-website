FOODIE FOOD ORDERING WEBSITE

Files:
- index.html: page structure
- style.css: styling and responsive layout
- script.js: menu, search, category filtering, cart quantities, subtotal and checkout demo

How to run:
1. Extract the ZIP.
2. Open the foodie_website folder.
3. Open index.html in your browser.
   Recommended: open the folder in Visual Studio Code and use the Live Server extension.

Notes:
- This is a front-end demo. Checkout does not submit a real order or accept payments.
- Food photos are loaded from Unsplash, so internet access is needed for those images.
- To receive real orders, add a backend/database and payment/delivery integration.
